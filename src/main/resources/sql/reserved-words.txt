# A generated name that is one of these is written quoted, in the case the database folds bare
# names to, so it is the column a bare name would be on a database that takes it bare.
# Listing a word a database does not reserve is harmless (the quoted name is the same column);
# leaving one out makes a project with that name fail on that database. DB2 for i and MySQL have
# no list of their own: they take every word listed here.
#
# [h2] is checked against H2 itself by SqlKeywordsTest. The others come from each database's
# documentation.
#
# A project on another database runs its own tests on H2, where a word that database takes bare is
# freed with H2's NON_KEYWORDS. Five words H2 does not free that way (CONSTRAINT, FOREIGN, PRIMARY,
# SET, and VALUES as a table), so they are on every list; SqlKeywordsTest holds this.
